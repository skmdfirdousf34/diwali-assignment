## Assignment Overview
This repository contains my completed work for "The Digital Detective" Diwali Independent Learning Assignment. Each mission in this assignment was completed individually in sequence, documented inside its own dedicated folder with its own `README.md`, and committed with descriptive git commit messages.

## Topics Explored
1. **Computer Hardware & IPOS Cycle**: Input, Processing, Output, and Storage architecture and everyday computer systems.
2. **Command-Line Interface (CLI)**: File navigation, directories, file manipulation, flags, pipes, and Homebrew package manager.
3. **Operating System Architecture**: macOS kernel details, storage usage, process identifiers (PIDs), file paths, and file permissions.
4. **Execution Models**: Compilers vs. Interpreters with a Python demonstration (`hello.py`).
5. **Data Representation & Encodings**: Manual and Python-verified conversions between Decimal, Binary, and Hexadecimal, ASCII vs UTF-8, and an interactive conversion script (`number_converter.py`).
6. **Version Control with Git**: Staging, commits, branching (`update-about`), and Pull Request workflows.
7. **Computer Networks**: LAN/MAN/WAN, DNS resolution, routing, packet switching, client-server models, and network diagnostic tools (`ping`, `nslookup`).

## My Learning
During the first five missions of this assignment, here are key concepts I have learned:
1. **Command Line Confidence:** I learned how to navigate directories and inspect system files using terminal commands like `pwd`, `ls -lah`, and pipes (`|`), which is much faster than using a GUI file manager.
2. **How the OS Manages Resources:** I discovered how processes are assigned unique PIDs and scheduled by the operating system kernel, and how file permissions (`rwx`) safeguard files across user accounts.
3. **Number Systems & Binary Logic:** Working through manual divisions and positional sums helped me connect why computers use binary at the hardware level and why hexadecimal is used as a convenient shorthand for 4-bit nibbles.
4. **Program Execution Models:** I gained a clear understanding of the difference between pre-compiled native binaries (like C/C++) and line-by-line runtime interpretation (like Python).
